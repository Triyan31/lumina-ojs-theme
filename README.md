# 🎨 Lumina OJS Theme

Official public information and comprehensive documentation for **Lumina Theme Framework** for Open Journal Systems (OJS).

## 📖 Tentang

Lumina adalah theme framework modern yang dirancang khusus untuk platform Open Journal Systems (OJS), menyediakan desain yang responsive dan customizable.

## ✨ Fitur

- 🎨 **Modern Design** - Interface yang clean dan professional
- 📱 **Responsive** - Optimal di desktop, tablet, dan mobile
- ⚙️ **Customizable** - Mudah dikustomisasi sesuai kebutuhan
- 🚀 **Performance** - Optimized untuk loading yang cepat
- 🌐 **Multilingual** - Support multiple languages

## 🚀 Quick Setup

```bash
# Clone repository
git clone https://github.com/Triyan31/lumina-ojs-theme.git

# Copy ke OJS themes directory
cp -r lumina-ojs-theme /path/to/ojs/public/themes/

# Activate theme di OJS admin panel
```
